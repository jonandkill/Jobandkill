- 본문 11pt, 기준선 20.35pt(185% 행간)

- 단면·연속 조판, 홀수 쪽 강제 시작 해제
- 장·절 제목의 페이지 말미 고립 방지
- 과도한 백지와 빈 내부 페이지 차단
- PDF·EPUB·HTML에 동일한 정보 위계 적용

## 콘텐츠 검수

- 제목, 저자 표기, 판권, 저자 소개, ‘이 책을 펴내며’ 수록
- 공공조직의 목적·규정·보고·협업·성과 판단 구조와 면접 답변 연결
- 사회복지사 자격 및 장애인 우대·제한경쟁 정보를 전체 취업 전략 안에서 별도 강조
- 기관별 지원자격·전형·면접·지역인재·거주지 제한·추가 자격을 표로 구조화
- 내부 제작 시방서·팀 회의록·출판사 전달 문구는 소비자 판매본에서 제거
- 원본 벡터 삽화에 제목과 설명을 포함해 접근성과 저작권 위험을 함께 관리

## 자동 검수

빌드 마지막 단계에서 `scripts/validate-publication.py`가 다음 항목을 검사한다.

1. PDF 빈 내부 페이지, 저자 메타데이터, 책갈피
2. EPUB 압축 무결성, mimetype, 삽화 포함 여부
3. HTML 최종 저자 표기와 내부 제작 문구 잔존 여부
4. 본문 1~13장 번호 연속성
5. 19/14/12/11pt 및 185% 조판 토큰
6. SVG 접근성 설명
7. 판매 ZIP의 PDF·EPUB·HTML·CSV·XLSX 포함 여부

실제 빌드 결과는 `dist/validation-report.json`, `dist/pdf-info.txt`, `dist/epub-validation.txt`, `dist/SHA256SUMS`에 기록된다. 페이지 끝의 짧은 제목 후보와 저밀도 페이지는 자동 탐지 후 별도 수동 확인 대상으로 남긴다.
