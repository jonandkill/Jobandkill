# 전자책 완성도 기준

## 1. 출간 판정

총점 100점 중 **90점 이상**이면서 아래 차단 항목이 모두 해소되어야 “출간 가능”으로 판정합니다. 점수와 무관하게 차단 항목이 하나라도 남으면 Release 태그를 만들지 않습니다.

### 절대 차단 항목

- 기관·공고·자격·일정에 출처 없는 단정이나 확인되지 않은 수치가 있음
- 데이터 기준일 또는 확인일이 누락됨
- “전국 모든 기관” 같은 포괄 표현에 실제 범위·누락 가능성 설명이 없음
- 원문 공고와 편집진의 분류·추론이 구분되지 않음
- 저작권·초상권·폰트·이미지 사용권 중 하나라도 미확정임
- 개인정보, 민감정보, 비공개 자료 또는 재배포 금지 자료가 포함됨
- EPUBCheck 실패, PDF 열기 실패, Pages 404 또는 주요 다운로드 링크 오류
- 표지·본문 이미지에 대체텍스트 또는 장식 이미지 표시가 누락됨
- 최종 저자·발행인·연락처·라이선스가 서로 불일치함

## 3. 데이터·사실 검수 규칙

### 필드 등급

| 등급 | 의미 | 표기 원칙 |
|---|---|---|
| 원문 사실 | 공고문·기관 채용 페이지에 직접 기재 | 출처 URL과 확인일을 함께 기록 |
| 편집 정규화 | 서로 다른 표현을 통일한 값 | 정규화 규칙을 데이터 사전에 공개 |
| 편집 추론 | 제목·공고 내용으로 판단한 지원 유형·난이도 등 | `추론`, `1차 분류`, `상세 확인 필요`로 명시 |
| 독자 전략 | 준비법·우선순위·면접 조언 | 사실처럼 단정하지 않고 적용 조건 제시 |

### 전수 검사

- 필수 열: 기관명, 공고명, 고용형태, 근무지역, 공고/접수 기간, 원문 URL, 출처 포털, 확인일
- URL 형식, 중복 공고, 마감일 역전, 빈 필수값, 날짜 형식, 기관명 표기 통일
- 지역 제한과 지역인재 가점은 별도 필드로 유지
- 필수 자격과 우대 자격을 별도 필드로 유지
- 장애·보훈·고졸 등 제한경쟁과 일반채용 내 우대를 구분
- 현재 공고와 과거 사례를 시각적으로 구분

### 표본 대조

- 기관 유형·지역·고용형태별로 최소 10건 또는 각 층의 10% 중 큰 값 대조
- 대형 공기업·병원·연구기관·지방 출자출연기관에서 각각 표본 포함
- 오류 발견 시 동일 수집 규칙을 적용한 전체 행을 재검사

## 4. 편집·윤문 기준

- 한 문단은 하나의 중심 메시지만 담고 첫 문장에 결론을 둡니다.
- `지원 가능`, `지원 유리`, `합격 가능`을 혼용하지 않습니다.
- `필수`, `우대`, `가점`, `제한`을 엄격히 구분합니다.
- 기관이 발표하지 않은 배수·컷·질문을 사실처럼 쓰지 않습니다.
- 면접 후기는 출처·시점·직렬 차이를 밝히고 일반화하지 않습니다.
- 같은 용어는 본문·표·부록·웹페이지에서 같은 표기를 사용합니다.
- 숫자, 날짜, 단위, 괄호, 영문 약어는 편집 스타일시트를 따릅니다.

## 5. 접근성 기준

- 제목은 H1 → H2 → H3 순서를 건너뛰지 않습니다.
- 색만으로 상태를 전달하지 않고 텍스트·아이콘을 함께 씁니다.
- 표에는 헤더가 있고, 복잡한 표는 앞뒤에 요약을 제공합니다.
- 정보 이미지에는 내용을 전달하는 alt를, 장식 이미지는 빈 alt를 제공합니다.
- 링크 문구는 `여기` 대신 목적지를 설명합니다.
- PDF에서 텍스트 선택·검색, 목차 이동, 한글 글리프 표시를 확인합니다.
- EPUB을 화면낭독기와 글자 크기 200% 이상에서 표본 검수합니다.

## 6. 기술 승인 증거

Release마다 다음 증거를 보관합니다.

- GitHub Actions 성공 실행 링크
- EPUBCheck 로그
- PDF `pdfinfo` 및 글꼴 포함 여부 확인 결과
- Pages 랜딩·본문·다운로드 링크 캡처 또는 검수 기록
- `SHA256SUMS.txt`
- 최종 검수자, 승인일, 데이터 기준일
