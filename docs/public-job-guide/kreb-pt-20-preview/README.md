# 한국부동산원 부동산 경제 직렬 PT 면접 예상질문 20선

> **JOB&KILL | 공개 소개·맛보기판 | 초판 2026년 9월**

이 저장소에는 전자책의 소개와 학습 방식을 보여 주는 맛보기만 공개합니다.  
**전자책 전문, 20개 주제별 완성 답안, 15개 실행안, 우선안·그래프 설계표는 포함하지 않습니다.**

## 이 책이 다루는 문제

부동산 경제 직렬 PT는 지식을 많이 나열하는 시험이 아닙니다. 제한된 발표 시간 안에 정책·통계·현장 문제를 연결하고, 실행 우선순위를 설명해야 합니다. 이 책은 국토교통부 업무계획(2021~2026), 한국부동산원 관련 공개자료, 국정감사 쟁점, 경영평가와 계약관리 쟁점을 바탕으로 연습 주제를 설계했습니다.

각 주제는 다음의 8단계로 풀도록 구성했습니다.

1. 주제와 문제를 한 문장으로 정의한다.
2. 관련 배경과 쟁점을 넓게 검토한다.
3. 가장 중요한 핵심 교집합 두 가지를 고른다.
4. 실현 가능한 실행 행동 15가지를 펼친다.
5. 영향·시급성·실행 가능성으로 우선안 2~3개를 고른다.
6. 막대·꺾은선·원 그래프의 역할을 구분한다.
7. 정책 메시지를 한 문장 결론으로 닫는다.
8. 부동산 경제 직렬에서 수행할 수 있는 역할로 연결한다.

## 학술 근거를 사용하는 방식

이 책은 한 편의 논문이 ‘8단계 구조가 면접 합격률을 높인다’고 증명했다고 주장하지 않습니다. 대신 능동적 학습, 자기설명, 인지부하 관리, 그래프 이해, 회상 연습의 연구 결과를 각 단계의 학습 원리로 연결합니다. 전문판에는 해당 근거와 적용 한계를 함께 적었습니다.

학술지 수록 확인은 Clarivate **Master Journal List** 기준으로 했습니다. 학습 근거는 Chi와 Wylie(2014), Chi 등(1994), Sweller 등(2019), Ainsworth(2006), Shah와 Hoeffner(2002), Butler(2010), Roediger와 Karpicke(2006)의 연구를 바탕으로 설명합니다.
