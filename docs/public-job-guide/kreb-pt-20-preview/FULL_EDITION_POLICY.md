# 전문판 제공·이용정책

## 1. 공개판과 전문판의 구분

이 저장소는 공개 저장소입니다. 따라서 이 경로에는 전자책의 **소개와 맛보기 자료만** 게시합니다.

전문판은 다음을 포함합니다.

- 전자책 전문 파일
- 20개 PT 예상 질문의 전체 8단계 답안
- 주제별 실행 행동 15개와 우선안
- 그래프 설계표와 참고문헌

위 자료는 공개 저장소·공개 링크·공개 다운로드에 올리지 않습니다.

## 2. 전문판 제공 방식

전문판은 구매자 또는 JOB&KILL이 승인한 수령인에게만 개별적으로 제공합니다. 제공 대상 확인 후 전자책 파일 또는 지정된 별도 접근 경로를 안내합니다.

공개 저장소를 보는 것, 이 맛보기 자료를 내려받는 것, 저장소를 포크하는 것은 전문판의 구매·이용·재배포 권한을 뜻하지 않습니다.

## 3. 이용 범위

전문판은 수령인 본인의 면접 준비와 학습 목적에 한해 이용할 수 있습니다. 다음 행위는 허용하지 않습니다.

- 전문판 전체 또는 일부의 복제·배포·전송·재판매·공유·게시
- 단체 수업, 컨설팅, 상업 콘텐츠, 문제은행의 재료로 사용하는 행위
- 파일 비밀번호·별도 접근 링크·개별 제공 경로를 제3자에게 전달하는 행위
- 저작권 표시를 삭제하거나 변경하는 행위

## 4. 권리와 책임

저작권은 JOB&KILL에 있습니다. 전문판 제공은 소유권이나 저작권의 이전이 아니라 제한된 개인 학습 이용권의 부여입니다.

이 자료는 면접 준비를 돕기 위한 학습 자료이며, 채용·합격 또는 특정 평가 결과를 보장하지 않습니다. 제도, 일정, 통계, 채용공고는 변동될 수 있으므로 실제 지원 전 해당 기관의 최신 공고와 공식 자료를 확인해야 합니다.

## 5. 공개판의 재배포

공개판 역시 저작권 보호 대상입니다. 인용이 필요한 경우에는 출처와 저작권자를 명시하고, 목적상 필요한 최소 범위만 사용해야 합니다. 공개판 전체를 다른 플랫폼에 재게시하거나, 유료 상품의 일부로 판매·배포하는 행위는 허용하지 않습니다.
