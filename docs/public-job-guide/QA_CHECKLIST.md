# 전국 공공부문 채용 전자책·데이터북 검수 기준

## 1. 목적과 적용 범위

이 문서는 일반 취업준비생을 대상으로 한 전국 공공기관·공기업·지방공기업·지방출자출연기관·시 산하 재단/사단법인 채용 전자책과 데이터북의 출간 전 검수 기준이다. 기관 목록, 현재 채용공고, 채용 절차, 면접 정보, 지역인재·지역제한, 장애인 관련 전형, 필수·우대 자격증, 출처 링크, 표와 수식, 전자책 접근성 및 GitHub 배포물을 모두 검수한다.

다음 원칙은 예외 없이 적용한다.

- **공고에 없는 내용을 사실처럼 쓰지 않는다.** 제목이나 기관 관행으로 필수자격·우대·전형을 추정하지 않는다.
- **지원자격과 우대사항을 분리한다.** 필수요건, 제한경쟁 대상, 가점, 동점자 우대, 서류 우대, 별도전형을 각각 구분한다.
- **현재 공고와 과거 전형정보를 분리한다.** 과거 공고나 면접 후기는 현재 전형의 확정 정보가 아니다.
- **기관 공식 공고 원문과 첨부파일을 최종 기준으로 삼는다.** 포털 요약과 원문이 다르면 정정공고를 포함한 최신 원문이 우선한다.
- **시점이 있는 모든 값에 기준시각을 둔다.** 날짜·시각은 대한민국 표준시(KST, UTC+9)로 표기한다.
- **법적·제도적 명칭을 임의로 바꾸지 않는다.** 장애인, 지역인재, 기관유형 등의 범주는 공고와 근거 규정의 표현을 유지한다.

## 2. 출간 차단 기준

아래 항목 중 하나라도 충족하지 못하면 출간·배포를 중단한다.

- [ ] 대상 공고마다 기관명, 공고명, 공고번호 또는 고유 ID, 원문 링크가 있다.
- [ ] 접수 시작일, 마감일과 **마감시각**, KST 기준 여부가 확인됐다.
- [ ] 지원자격, 제한조건, 결격사유, 필수자격증이 공고 원문 및 첨부파일과 일치한다.
- [ ] 장애인·지역인재 항목이 `지원자격/제한경쟁/가점/우대/해당 없음/확인 필요` 중 하나로 명확히 구분됐다.
- [ ] `진행중` 표시는 검수 기준시각에 실제 접수 가능한 공고에만 사용했다.
- [ ] 모든 핵심 원문 링크를 직접 열어 해당 공고임을 확인했다.
- [ ] 데이터북의 주요 집계값이 원자료 행 수 및 필터 결과와 일치한다.
- [ ] 수식 오류와 깨진 내부·외부 링크가 없다.
- [ ] 전자책 본문과 데이터북 사이의 기관명, 공고명, 날짜, 자격요건이 일치한다.
- [ ] 장애인·지역인재·연령·거주지 관련 표현에 차별적·단정적·오해 소지가 없다.
- [ ] 출처·확인일·면책 고지와 이미지 라이선스가 포함됐다.
- [ ] EPUB/PDF/HTML 또는 GitHub 배포본의 읽기 순서, 대체텍스트, 표 머리글 등 핵심 접근성을 확인했다.

### 출처 기록 최소 필드

- [ ] 원문 URL과 공고 첨부파일 URL을 각각 기록했다.
- [ ] 공고번호 또는 포털 고유 ID를 기록했다.
- [ ] 출처 구분(`기관 원문/공식 포털/공식 제도자료/과거 공식자료/비공식 후기`)을 기록했다.
- [ ] 최종 확인일시를 `YYYY-MM-DD HH:mm KST`로 기록했다.
- [ ] 정정공고 여부, 정정일, 변경된 항목을 기록했다.
- [ ] 웹페이지가 사라질 경우를 대비해 기관명·게시판명·공고번호·게시일을 남겼다.

## 4. 전체 범위와 기관 분류 검수

`전국 모든 기관`은 기준일 현재 공식 목록에서 확인되는 모집단을 뜻한다. `모든 기관이 현재 채용 중`이라는 의미로 사용하지 않는다.

- [ ] 기준일과 포함 범위를 서문에 명시했다.
- [ ] 중앙 공공기관과 지방공공기관의 공식 목록 건수를 각각 원자료와 대조했다.
- [ ] 기관의 공식 명칭을 축약명과 혼용하지 않았다.
- [ ] `공기업/준정부기관/기타공공기관/지방공사/지방공단/지방출자출연기관/지자체 산하 법인/기타 비영리법인`을 공식 분류 또는 별도 범주로 구분했다.
- [ ] 재단법인·사단법인이라는 법인 형태만으로 `공공기관` 또는 `공기업`이라고 단정하지 않았다.
- [ ] 기관 통폐합, 명칭 변경, 지정 해제·신규 지정을 기준일 현재 상태로 반영했다.
- [ ] 동일 기관이 포털 두 곳에 노출될 경우 기관 식별자와 공고번호로 중복을 제거했다.
- [ ] 본원·지역본부·수탁기관 공고를 임의로 하나의 기관으로 합치지 않았다.
- [ ] `현재 채용 없음`, `채용 확인 필요`, `채용 중`을 구분했다.
- [ ] 누락·중복 검증 결과와 제외 사유를 검수 기록에 남겼다.

## 5. 공고별 사실검증 체크리스트

### 5.1 공고 식별과 시점성

- [ ] 기관명, 공고명, 채용분야, 고용형태, 신입/경력 구분이 원문과 일치한다.
- [ ] 공고 게시일, 접수 시작일, 마감일, 마감시각을 별도 필드로 기록했다.
- [ ] `오늘/내일/D-day` 같은 상대 날짜 대신 절대 날짜를 기본으로 사용했다.
- [ ] `진행중` 상태를 단순 공고 게시 여부가 아니라 접수기간으로 계산했다.
- [ ] 조기마감, 상시채용, 채용 시 마감, 이메일 접수 등 예외를 별도 표시했다.
- [ ] 마감 당일에는 원문에서 연장·취소·정정 여부를 다시 확인했다.
- [ ] 모집인원, 근무지, 임용예정일, 계약기간, 근무시간이 원문과 일치한다.
- [ ] 채용취소·재공고·기간연장 공고를 이전 버전과 혼동하지 않았다.

### 5.2 일반 취업준비생 지원 가능성

- [ ] `일반지원 가능`은 필수 학력·경력·자격·연령·신분·거주 요건을 모두 확인한 경우에만 표시했다.
- [ ] 제목의 `신입`, `인턴`, `일반직`만으로 일반지원 가능 여부를 추정하지 않았다.
- [ ] 청년인턴은 공고의 청년 연령 기준과 예외 조항을 확인했다.
- [ ] 체험형 인턴과 채용형 인턴을 구분했다.
- [ ] 무기계약직, 공무직, 기간제, 정규직, 정규직 전환형을 정확히 구분했다.
- [ ] `학력무관`과 `전공무관`을 혼용하지 않았다.
- [ ] 블라인드 채용이라도 직무 관련 자격·경력 증빙은 요구될 수 있음을 반영했다.

### 5.3 자격요건·자격증·증빙

- [ ] 필수자격과 우대자격을 별도 열과 본문으로 분리했다.
- [ ] 자격증 명칭, 급수, 발급기관, 유효기간, 취득 기준일을 원문 그대로 확인했다.
- [ ] 사회복지사 자격증은 `1급/2급/등급 무관/취득예정 인정 여부`를 구분했다.
- [ ] 한국사능력검정시험은 필수인지, 가점인지, 등급·유효 인정기준이 무엇인지 확인했다.
- [ ] 어학점수는 시험 종류, 최저점수, 유효기간, 사이버국가고시센터 사전등록 인정 여부를 확인했다.
- [ ] 운전면허, 전산, 안전·기술 자격 등은 실제 직무별 필수/우대 조건과 대조했다.
- [ ] 경력 연수, 경력 산정 기준, 재직/경력증명서 요구 항목을 확인했다.
- [ ] 졸업예정·자격취득예정·합격예정 인정 여부를 추정하지 않았다.
- [ ] 병역, 연령, 결격사유, 임용 가능일 등 공통요건을 누락하지 않았다.
- [ ] 증빙서류의 발급 기준일과 제출 시점을 확인했다.

## 6. 장애인 관련 표현과 전형 검수

`장애의 정도가 심한 장애인`과 고용관계 법령상 `중증장애인`은 근거 법령과 적용 범위가 다를 수 있으므로 임의로 같은 뜻으로 치환하지 않는다. 공고가 사용한 용어와 증빙기준을 그대로 제시한다.

- [ ] `장애인 제한경쟁`, `장애인 별도전형`, `장애인 가점`, `동점자 우대`, `우대 없음`을 구분했다.
- [ ] `장애인 우대`를 `장애인만 지원 가능`으로, 또는 그 반대로 해석하지 않았다.
- [ ] `장애의 정도가 심한 장애인`, `중증장애인`, `등록장애인`을 공고 원문 및 근거 법령에 맞게 사용했다.
- [ ] 과거 장애등급제 표현을 현재 제도에 임의 적용하지 않았다. 과거 자료 인용 시 당시 표현임을 밝혔다.
- [ ] 가점률, 적용 전형, 중복가점 방식, 가점 적용 최저점 기준을 확인했다.
- [ ] 장애인 증명서, 복지카드, 국가유공자 관련 증빙 등 인정서류와 발급 기준일을 확인했다.
- [ ] `심한 장애` 여부가 실제 지원자격 또는 가점에 영향을 주는지 공고 문구로 확인했다.
- [ ] 장애 유형·정도에 따른 직무수행 가능성을 편견이나 추정으로 평가하지 않았다.
- [ ] 편의지원 신청기한, 신청방법, 제출서류, 제공 가능한 지원을 별도 안내했다.
- [ ] 개인정보에 해당하는 장애 관련 증빙을 데이터나 저장소에 포함하지 않았다.

### 권장 표기 예시

- `장애인: 서류전형 만점의 5% 가점(공고상 증빙요건 충족 시)`
- `장애인 제한경쟁: 등록장애인만 지원 가능`
- `장애 정도: 공고에서 별도 구분하지 않음`
- `중증/심한 장애 관련 추가 우대: 공고 원문 확인 필요`

다음과 같은 단정 표현은 금지한다.

- `심한 장애인은 무조건 가산점`
- `장애인이면 합격 가능성이 높음`
- `복지카드만 있으면 지원 가능`
- `장애 정도와 관계없이 동일` — 공고 확인 없이 사용 금지

## 7. 지역인재·지역제한 검수

근무지가 지방이라는 이유만으로 지역인재 채용이라고 판단하지 않는다. `지역인재 우대`와 `해당 지역 거주자만 지원 가능한 지역제한`은 완전히 다른 항목이다.

- [ ] `이전지역인재`, `비수도권 지역인재`, `지역인재`, `지역제한`, `지역전문사원` 등 공고상의 용어를 그대로 기록했다.
- [ ] 적용 기준이 학교 소재지인지, 주민등록 거주지인지, 출생지인지, 근무 희망지역인지 확인했다.
- [ ] 고등학교·대학교 중 어느 학력을 기준으로 하는지 확인했다.
- [ ] 졸업·재학·졸업예정 인정범위와 예외학교를 확인했다.
- [ ] 거주 시작일, 기준일, 연속/합산 거주기간, 접수일 이후 전입 인정 여부를 확인했다.
- [ ] 가점, 채용목표제, 별도모집, 지원자격 제한 중 어떤 방식인지 구분했다.
- [ ] 지역인재 목표비율을 개인에게 자동 부여되는 가점처럼 표현하지 않았다.
- [ ] 본사 이전지역과 실제 근무지가 다른 경우 각각 표기했다.
- [ ] 지역 구분이 불명확하면 `해당 없음`이 아니라 `원문 확인 필요`로 표시했다.

## 10. 데이터북 표·수식·필터 검수

### 10.1 구조와 데이터 품질

- [ ] 한 행은 한 공고 또는 한 세부 채용분야라는 원칙을 문서화했다.
- [ ] 병합셀 없이 머리글이 한 행으로 구성돼 필터·정렬이 가능하다.
- [ ] 날짜는 텍스트가 아닌 날짜/시각 형식으로 저장하고 표시 형식을 통일했다.
- [ ] 기관명·지역·고용형태·지원유형 값의 철자와 분류값을 표준화했다.
- [ ] 빈칸, `없음`, `해당 없음`, `미확인`을 구분했다.
- [ ] 중복키(`출처포털 + 공고ID + 세부직무`)로 중복 행을 검사했다.
- [ ] 숨김 행·열·시트에 오래된 값이나 개인정보가 남아 있지 않다.
- [ ] 필터 범위가 마지막 데이터 행까지 포함된다.
- [ ] 틀 고정, 열 너비, 줄바꿈, 글꼴 크기로 핵심 정보가 잘리지 않는다.
- [ ] URL 셀과 표시 텍스트가 서로 다른 공고를 가리키지 않는다.

### 10.2 수식과 집계

- [ ] 전체 행 수 = 상태별·기관유형별·고용형태별 합계와 일치한다.
- [ ] `현재 채용`, `마감 임박`, `일반지원 가능`, `장애인 관련`, `지역 관련` 집계식을 각각 원자료 필터와 대조했다.
- [ ] 수식 참조범위가 신규 행까지 확장된다.
- [ ] 계산 모드가 자동이며 저장 전 재계산됐다.
- [ ] `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#NUM!`, 의도하지 않은 `#N/A`가 없다.
- [ ] 0과 빈칸을 같은 값으로 처리해 집계가 왜곡되지 않는다.
- [ ] 날짜 경계 계산에 KST와 마감시각이 반영됐다.
- [ ] 하드코딩된 합계가 아니라 검증 가능한 수식을 사용했다.
- [ ] 피벗·차트·대시보드의 원본 범위와 새로고침 상태를 확인했다.
- [ ] 무작위 표본 10건 이상을 원공고와 셀 단위로 교차검증했다.

### 10.3 데이터 검증 규칙 권장값

- 채용상태: `접수예정/접수중/마감/상시/취소/확인 필요`
- 일반지원: `가능/조건부 가능/제한경쟁/경력·전문/확인 필요`
- 고용형태: `정규직/채용형 인턴/체험형 인턴/무기계약직·공무직/기간제/기타`
- 장애인 관련: `지원자격/제한경쟁/별도전형/가점/동점자 우대/일반적 우대/없음/확인 필요`
- 지역 관련: `지원자격/별도모집/가점/목표제/동점자 우대/없음/확인 필요`
- 검증상태: `원문 확인/포털만 확인/과거자료/비공식 참고/미검증`

| **P3 경미** | 사실·지원판단에 영향이 거의 없는 편집상 결함 | 맞춤법, 띄어쓰기, 문장 반복, 사소한 여백·폰트 불일치 | 일괄 교정 후 표본 확인. 미수정 상태로도 긴급 배포 가능하나 다음 릴리스에 반영 |

### 등급 판정 보정 규칙

- 같은 P2/P3 오류가 반복돼 여러 공고에 영향을 주면 한 단계 상향한다.
- 자격, 마감, 장애인, 지역제한, 개인정보 관련 오류는 보수적으로 상향한다.
- 원문 확인 없이 추정한 값이 핵심 필드에 들어가면 실제 값이 우연히 맞더라도 P1 이상으로 본다.
- 정정공고가 검수 후 게시된 경우 제작 오류와 구분해 `시점 변경`으로 기록하되 즉시 최신판 반영 여부를 결정한다.

## 16. 검수 범위와 표본 원칙

- **100% 전수검수:** 기관·공고 식별, 원문 링크, 접수 마감, 필수자격, 지원제한, 장애인·지역인재 적용 방식, 개인정보, P0/P1 수식.
- **자동검사 + 육안검수:** 링크 상태, 중복, 날짜 형식, 허용값, 수식 오류, 이미지 경로, 목차 링크.
- **최소 표본검수:** 나머지 설명 필드는 기관유형·지역·고용형태별로 층화해 10건 이상 또는 전체의 10% 중 큰 값을 검사한다. 표본에서 P1 이상 오류가 나오면 같은 유형을 전수검수한다.
- **2인 교차검수:** P0/P1 수정, 장애·지역제한 판정, 출간본의 총계, 최종 면책 고지는 작성자 외 검수자가 승인한다.
